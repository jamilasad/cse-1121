2D arrays

A table, or an array of arrays.

Every box has two names: row i, column j of a table, or box j of the array a[i]. Use the one that makes the problem easy.

Steps 3 to 7 use this grid. R and C from 1 to 6; the values row by row.

Step 1

Declare it, and name every box

int a[4][5]; makes a grid of 4 rows and 5 columns: 20 int boxes. The box a[i][j] is in row i and column j. Click any box.

Your turn

What is the name of the last box of int a[4][5];?

a[3][4], not a[4][5]. Rows go 0 to 3, columns go 0 to 4.

2
Step 2

Use one box, like a variable

Each box is one int. You can put a value in it, use it in a sum, read it with scanf, and print it. The input here is 9.

3
Step 3

Two ways to see it

As a table: rows and columns. As an array of arrays: a has 4 boxes, a[0] to a[3]. Each box is a whole 1D array of 5 numbers. So a[1][2] is box 2 of the array a[1].

For columns and diagonals, think of a table (tabs 2 and 3). For work done row by row, think of 1D arrays, and reuse what you know (tab 4).

Hint · Where is it in memory?

Memory has no table. Row 0, row 1, row 2 … sit one after another in one long line.

Step 2

    
The main diagonal

    
Your turn

      
The main diagonal is a[0][0], a[1][1], a[2][2], a[3][3]. What do you see in the two indices?

      
      
They are always equal. So one variable is enough: a[i][i].

    

    

  


  
3
Step 3

    
The other diagonal: one goes up, one goes down

    
It is a[0][3], a[1][2], a[2][1], a[3][0]. The first index goes up and the second goes down, like i and j in the palindrome.

    

    
i + j is always N - 1, so a[i][N - 1 - i] also works. Two variables are easier to see.

Transpose: rows become columns

    
Your turn

      
a is 3 × 4. Its transpose b has row 0 of a as its column 0. What size is b, and where does a[i][j] go?

      
      
b is 4 × 3. a[i][j] goes to b[j][i]: only the two indices swap places.

    

    

  


  
What we learned

    
    
      
  1. For whole matrices, think of a table: the same [i][j] in every grid.
