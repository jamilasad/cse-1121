2D arrays

A table, or an array of arrays.

Every box has two names: row i, column j of a table, or box j of the array a[i]. Use the one that makes the problem easy.

Steps 3 to 7 use this grid. R and C from 1 to 6; the values row by row.

Your turn

Use one box, like a variable

Each box is one int. You can put a value in it, use it in a sum, and print it.

3
Step 3

Two ways to see it

As a table: rows and columns. As an array of arrays: a has 4 boxes, a[0] to a[3]. Each box is a whole 1D array of 5 numbers. So a[1][2] is box 2 of the array a[1].

For columns and diagonals, think of a table (tabs 2 and 3). For work done row by row, think of 1D arrays, and reuse what you know (tab 4).

Hint · Where is it in memory?

Memory has no table. Row 0, row 1, row 2 … sit one after another in one long line.

A picture is a 2D array

    
Make a picture move

    
This is where we are going. Press Run and watch the two men.

    

    
It looks hard, but we will build it in small steps. Sit tight and go along with each step. In the end, the picture lives in a 2D array.

    
Copy any program and run it on your computer. The terminal window must be at least 30 columns wide.

  


  
1
Step 1

    
Print a picture

    
Four printf calls draw the man. The terminal starts writing at the top-left corner.

    

  


  
2
Step 2

    
Put it anywhere

    
The terminal is a grid of characters. Columns go to the right and lines go down. Both start at 1.

    
gotoxy(x, y) moves the cursor to column x, line y. The next printf writes from there. You do not need to know how it works inside: just call it.

    
printf("\033[2J"); clears the screen first. Without it, the man is drawn over the text that is already in the window. \033 is the Esc character. The terminal reads Esc [2J as an order, not as text to print. gotoxy uses the same idea. On Windows we write system("cls"); instead.

    

    
What next?

      
Only the first line moved. The other lines are at the left edge again. Why? How do we put every line under the first one?

      
      
\n sends the cursor to column 1 of the next line. So each line needs its own gotoxy(left, top + 1), gotoxy(left, top + 2) …

    

    

  


  
3
Step 3

    
Make it move

    
Put the 8 lines in a loop that runs 10 times.

    

    
What next?

      
The loop runs 10 times, but the man does not move. How do we move him one column each time?

      
      
Draw him at left + step instead of left. step is 0, 1, 2 …, so the column grows by one. A short wait lets us see each move.

    

    

    

    
He leaves a trail. The old stars stay on the screen. So after the wait, we write spaces over him, and then move.

    

    

  


  
4
Step 4

    
Keep the picture in a 2D array

    
Look at step 3 again. One man needs 8 lines to draw and 8 lines to erase. A second man needs 16 more lines, and a new picture means changing every printf. The code is getting messy.

    
So we keep the picture as data, in a 2D array. Then we write the drawing code only once.

    
Each row of the picture is a row of man. 1 means a star and 0 means a space. Printing it is the nested loop from tab 1.

    

      
New · A global variable

      
man is declared outside main, so every function in the file can use it. This is a global variable.

      
We do this because we have not learned how to pass an array to a function yet.

    

    

  


  
5
Step 5

    
A function that draws it at (x, y)

    
drawMan(x, y) draws the man with his top-left corner at column x, line y. Row i of man goes to line y + i. Box j goes to column x + j.

    
There is no \n now: gotoxy starts every row. main calls it with left and top. Inside drawMan, the same numbers are called x and y.

    

  


  
6
Step 6

    
Erase it, then one function for both

    
eraseMan writes spaces over the man. fflush(stdout) is new. Without \n, printf may keep the stars in memory. fflush puts them on the screen before the wait.

    

    
What next?

      
drawMan and eraseMan are almost the same. How can one function do both?

      
      
Give it one more parameter, show. Print a star only when show == 1 and the box is 1. Otherwise print a space.

    

    

  


  
7
Step 7

    
Move it, then two of them

    
The loop of step 3 again, but now each move is 3 short lines: draw, wait, erase.

    

    

    
A second man starts 20 columns to the right and walks left: left + 20 - step. After 9 moves they are face to face.

    

    

  


  
8
Step 8 · optional

    
Make it a story

    
Row 4 of man holds a second pair of legs. drawMan takes the legs from row legRow of man. After each move, legRow switches: 3, 4, 3, 4 … So the men walk.

    
A ground line goes under their feet. On the last move we do not erase them, and they say Hi!
